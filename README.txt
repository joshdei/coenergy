CO ENERGY — WEBSITE
====================
Files:
- index.html
- css/style.css
- js/app.js
- assets/ (place your real product/company images here)

FEATURES:
- Responsive international-style solar company/e-commerce design
- Product catalog and category filters
- Shopping cart with localStorage
- Product search overlay
- WhatsApp checkout
- Mobile navigation
- Company/about/contact CTA

WHATSAPP:
Open js/app.js and replace:
YOUR_WHATSAPP_NUMBER
with the company's WhatsApp number in international format, digits only.
Example: 15551234567

PRICES:
Demo prices are in USD. Edit the products array in js/app.js to use the company's real products/prices.

IMAGES:
The current demo uses CSS-generated product visuals so the website works immediately.
Replace the .product-visual blocks with <img> elements when real product photos are available.
